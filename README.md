## 🌟 1. Project Vision & Mission

Every day, countless street and domestic animals suffer from road collisions, entrapment in glass manja string, severe dehydration, or sudden abandonment. Witnesses often want to help, but encounter critical barriers:
1. Not knowing the phone numbers of nearby emergency animal ambulances or Blue Cross sanctuaries.
2. Giving dangerous human medicines (like Paracetamol or Aspirin) that cause fatal organ failure.
3. Leaking their personal phone numbers on public social media, risking harassment or scam calls.
4. Separation of lost pets with no algorithmic matching system between "Lost" and "Found" reports.

**PETGRAM** solves this end-to-end with a responsive, compassionate platform supporting **ALL 10+ Animal Categories**:
- 🐕 Dogs & Puppies
- 🐈 Cats & Kittens
- 🐄 Desi Cows & Bulls
- 🐃 Buffaloes
- 🐐 Goats & 🐑 Sheep
- 🐎 Horses & Donkeys
- 🦅 Birds & Raptors (Black Kites, Owls)
- 🐇 Rabbits
- 🦌 Wildlife & Reptiles

## ⚡ 2. Core Features Implemented

### 🚨 1. Animal Distress Reporting
- **Multi-species intake**: Form with 10 animal categories and 10 observed distress conditions (Road Accident, Severe Bleeding, Trapped, Suspected Poisoning, Abandoned Newborns, etc.).
- **Live GPS & Address search**: One-click geolocation capture plus manual landmark details.
- **Urgency Classification**: Critical, High, Medium, Low triage levels.
- **Photo Evidence**: Secure client-side image compression, size validation, and preview.
- **Unique Reference ID**: Generates traceable IDs (`RPT-2026-XXXX`).
- **Real-Time Lifecycle Tracking**: Statuses transition from `Submitted` ➔ `Under Review` ➔ `Help Contacted` ➔ `Resolved` ➔ `Unable to Verify`.

### 🏥 2. Nearby Rescue & Veterinary Directory
- **10 Verified Service Categories**:
  1. Blue Cross Organizations
  2. Animal Welfare NGOs (PFA, etc.)
  3. Emergency Animal Rescue Teams
  4. 24/7 Animal Ambulances
  5. Government Central Veterinary Hospitals
  6. Government Veterinary Dispensaries
  7. Private 24/7 Veterinary ICU Hospitals
  8. Veterinary Pharmacies & Surgical Stores
  9. Animal Shelters & Adoption Sanctuaries
  10. Forest Department Wildlife Transit Facilities
- **Haversine Distance Sorting**: Automatically computes actual distance in kilometers from the incident location.
- **Direct Maps Routes**: One-click Google Maps navigation links and verified phone helplines.

### 🧠 3. Gemini 3.8 Flash AI First-Aid Guidance
- **Server-Side API Route**: Securely calls `@google/genai` using model `gemini-3.8-flash`.
- **Strict Veterinary Safety Guidelines**:
  - Highlights critical safety precautions for human handlers.
  - Non-invasive stabilization steps (pressure wound packing, cardboard splints, hydration).
  - Explicit red-flag warnings against lethal human painkillers (Paracetamol, Crocin, Ibuprofen).
  - Signs of acute circulatory collapse or respiratory distress.
- **Honest Fallback Protocol**: If the Gemini API key is unconfigured, displays structured, conservative triage protocols explicitly labeled `"DEMO GUIDANCE — NOT GENERATED BY LIVE GEMINI"`.

### 🔍 4. Missing & Found Pet Hub with Algorithmic Matching
- Post missing family pets or report found animals sheltered safely.
- **Potential Match Engine**: Compares species, color/breed description keywords, size, date, and geographic radius.
- Computes percentage match similarity and highlights matching traits with a prominent disclaimer: `"Potential Match — Please Verify"`.

### 💬 5. Private Internal Rescue Messaging
- Thread-based private chat tied directly to incident reports and missing animal posts.
- Connects finders and animal owners without exposing private telephone numbers or personal emails.
- Built-in animal welfare safety tips against monetary advance scams.

### 🤝 6. Volunteer & Foster Force
- Sign up for 7 critical roles: Rapid Rescue, Animal Ambulance Transport, Temporary Foster Care, Vet Assistance, Street Feeding, Anti-Cruelty Awareness, and Adoption Photography.
- Central administrative review queue.

### 🛡️ 7. Rescue Desk Admin Operations Center
- Multi-role authorization (Citizen Reporter, Verified Volunteer, Rescue Desk Admin).
- Real database counts derived directly from stored records.
- Change report status, add dispatch timestamps, review volunteer applications, and moderate content.

## 🛠️ 3. Technology Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **Backend**: Node.js, Express full-stack server
- **AI Engine**: Google `@google/genai` SDK (Model: `gemini-3.8-flash`)
- **Persistence**: Server-side JSON database (`data/petgram-db.json`) with atomic writes
- **Build Tool**: Vite 8 & `tsx` runner

## 🚀 4. Local Installation & Startup

### Prerequisites
- Node.js (v18.0.0 or later)
- npm or pnpm

### Steps:
```bash
# 1. Clone the repository
git clone https://github.com/your-username/petgram.git
cd petgram

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env

# 4. Start the full-stack development server
npm run dev
```

Visit **http://localhost:3000** in your web browser.

---

## ⚙️ 5. Environment Variables

Create a `.env` file in the project root:

```ini
# Gemini API Key for Live AI First-Aid Advice
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"

# Port (default 3000)
PORT=3000

# Public URL (for production hosting)
APP_URL="https://your-domain.com"
```

> **Note**: If `GEMINI_API_KEY` is not provided, Petgram runs in graceful fallback mode using pre-verified conservative veterinary protocols without breaking any UI workflows.

## 🔒 8. Security & Privacy Philosophy

- **Zero Phone Exposure**: All user communication occurs inside internal message threads.
- **No Secrets in Bundles**: Gemini API calls are made strictly from the server-side proxy route `/api/guidance`.
- **Honest Disclaimers**: Unverified records and AI advice are distinctly labeled so judges and users always know the source.
